Sourcing Orders - catalogue to vendor PO

Flow: select items + qty from the catalogue → download the order sheet and send it to the vendor → vendor confirms → import the confirmed sheet → item master is created (SAHI item code, vendor code, auto EAN-13 barcode, friendly name, unit price) → vendor PO is generated.

3Vendor confirmed - import the returned sheet

Must contain a Vendor SKU column and a Qty column. Confirmed Price / Unit Price column is optional.

4Create item master + barcode, then generate PO

Items are created per vendor with: item code (SAHI code = vendor SKU, editable above), vendor code, auto EAN-13 barcode, friendly name, unit price. Then one PO per vendor is generated (RMB, DRAFT).
